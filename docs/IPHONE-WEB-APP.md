# Install on iPhone as an offline web app (no Mac needed)

The web build includes a service worker (`out/sw.js`, generated by
`scripts/generate-sw.mjs`) that stores every page on the phone. iOS only
allows this over **HTTPS**, so the static files are put on a free HTTPS host.
Only the app's code is uploaded. **Your data stays on the iPhone** (IndexedDB)
and is never sent anywhere.

## First install

1. `npm run build` creates the `out/` folder.
2. Go to <https://app.netlify.com/drop>, sign in with a free account (so the
   site is kept), and drag the **`out`** folder onto the page.
3. Netlify gives you a link like `https://something.netlify.app`. In
   *Site configuration → Change site name* you can rename it, e.g. `my-uniflow`.
4. On the iPhone, open the link in **Safari**, wait for the dashboard, then
   **Share → Add to Home Screen**.
5. Open Flowed from the Home Screen icon once while online. From then on it
   works in airplane mode.

## Updating

Run `npm run build` again and drag the new `out` folder onto your site's
**Deploys** tab (or run `npm run deploy:netlify` after `npx netlify-cli login`).
Next time the iPhone app opens online it downloads the new version in the
background; close and reopen it to switch over. Your data is kept.

## Good to know

- Use the **Home Screen icon**, not a Safari tab. iOS may clear website
  storage for sites you haven't opened in a while, but Home Screen apps are
  treated as installed apps.
- Export a backup now and then (**Settings → Export backup**). It's your copy
  if the phone is lost or storage is ever cleared.
- **Reminders while Flowed is closed:** Home Screen web apps can't schedule
  notifications without a push server, so use **Settings → Calendar sync → Add to
  Calendar**. iPhone Calendar then fires the alarms (tasks, exams, and classes
  every week). Re-add it after big changes; delete the old Flowed calendar first
  to avoid duplicates.
- **While Flowed is open:** heads-ups pop up as toasts and, after you tap
  *Allow notifications* in the bell panel, as notifications (iOS 16.4+).
- **Photo import:** the scanner (about 6 MB) downloads the first time you scan
  while online, then works offline.
- Cloudflare Pages or GitHub Pages work the same way. `out/_headers` is
  honoured by Netlify and Cloudflare.
