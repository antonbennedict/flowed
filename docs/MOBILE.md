# Android & iOS builds

Flowed is a static export (`out/`), and Capacitor bundles it into native shells (`android/`, `ios/`). App id: `com.uniflow.app`. Config: `capacitor.config.ts`.

Every time you change web code: `npm run cap:sync`, which runs `next build` and then `cap sync`.

## Android (APK)

**Requirements:** Android Studio (latest stable) with Android SDK Platform 36 (`compileSdk`/`targetSdk` 36, `minSdk` 24), and **JDK 21**. The project compiles to Java 21 with Gradle 8.14.3 / AGP 8.13. Gradle 8.14 can't *run* on newer JDKs such as Java 26, so point `JAVA_HOME` at Android Studio's bundled JBR:

```powershell
# Windows (PowerShell)
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
```
```bash
# macOS
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
export ANDROID_HOME="$HOME/Library/Android/sdk"
```

```bash
npm install
npm run android:apk
# → android/app/build/outputs/apk/debug/app-debug.apk
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

Or run `npm run android:open` and use **Run ▶** in Android Studio on a device or emulator.

**Release build** (signed APK/AAB):

1. Create a keystore once: `keytool -genkey -v -keystore uniflow.jks -alias uniflow -keyalg RSA -keysize 2048 -validity 10000`. Keep it safe and **don't commit it**.
2. Add the signing config to `android/app/build.gradle` (or use Android Studio → *Build → Generate Signed Bundle / APK*).
3. Run `npm run android:release`. Output goes to `android/app/build/outputs/{bundle,apk}/release/`.

Notes:
- `POST_NOTIFICATIONS` (Android 13+), `SCHEDULE_EXACT_ALARM` and `RECEIVE_BOOT_COMPLETED` are merged in from the notifications plugin, which re-registers scheduled reminders after a reboot. Flowed also re-syncs every reminder from the database on each launch.
- `adjustResize` together with Capacitor Keyboard `resize: "native"` keeps focused inputs above the keyboard.
- The hardware **back** button closes an open dialog, sheet or menu first, then navigates back, and exits only from the dashboard (`native-bridge.tsx`).
- The notification small icon is `res/drawable/ic_stat_uniflow.xml`.

## iOS (Xcode)

**Requirements:** a Mac with the current stable Xcode (the project targets iOS 15.0+ and uses Swift Package Manager, so CocoaPods isn't needed) and an Apple ID. A free account can install on your own device; App Store or TestFlight distribution needs the Apple Developer Program.

```bash
npm install
npm run ios:open        # builds, syncs, opens ios/App/App.xcodeproj
```

In Xcode: select the **App** target → *Signing & Capabilities* → choose your Team and a unique bundle id. Then pick a device or simulator and press **Run**. For distribution, use *Product → Archive → Distribute App*.

Notes:
- The project was generated on Windows. The first Xcode open resolves the Swift packages from `node_modules`, so run `npm install` on the Mac first.
- The SQLite file lives in the app's `Library/CapacitorDatabase/` folder (`iosDatabaseLocation` in `capacitor.config.ts`). Use the in-app JSON export to move data between devices.
- `UIFileSharingEnabled` makes exported backups visible in **Files → On My iPhone → Flowed**.
- Local notifications ask for permission the first time you tap **Allow notifications** in Settings. iOS keeps at most 64 pending notifications, so Flowed schedules the soonest 60.

## Icons & splash screens

Sources live in `resources/` and are generated by `npm run icons` from the same mark as the in-app logo. Native assets are generated with:

```bash
npm run assets   # capacitor-assets --android --ios (does not touch public/)
```

Don't run `capacitor-assets generate` without `--android --ios`: its PWA step overwrites `public/manifest.webmanifest`.

## Offline behaviour

The app bundle contains every page, script and the font. Nothing is fetched at runtime. Data persistence:
- SQLite on device, persisted across app restarts and updates. It is removed only if the app is uninstalled (on Android, auto-backup may restore it after a reinstall).
- In browsers, IndexedDB with `navigator.storage.persist()` requested. Clearing site data removes it, so use **Export backup**.
